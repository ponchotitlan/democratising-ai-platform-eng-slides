About the session

Agents are easy to demo and hard to run. The session was about the platform engineering around them: giving agents an identity, the right tools and the right knowledge, then being able to answer who approved an action and what happened afterwards. We looked at how CAIPE, an open-source AI platform, puts those pieces together, and watched it handle a live incident in the LedgerLite demo.

Try it, then make it better. The best way to judge CAIPE is to run it, and the Learning Lab above takes a few minutes. If you hit a rough edge, or found a clever way to make it work in your own environment, share it. Open-source grows from stories from the trenches: a bug report, a guide, a question or a pull request all count.

Start a conversation or open an issue on the CAIPE repository on GitHub. I would love to hear yours.
